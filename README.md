 Project Description
ExoHabitAI is a Streamlit-based AI application that predicts and analyzes exoplanet habitability using machine learning models.

---

 🛠️ Technologies Used
- Python
- Streamlit
- Machine Learning
- Pandas
- Scikit-learn

---
# ▶️ How to Run Locally

1. Clone the repository:
   git clone https://github.com/GKSJ19/ExoHabitAI.git

2. Navigate to project folder:
   cd ExoHabitAI

3. Install requirements:
   pip install -r requirements.txt

4. Run the app:
   streamlit run streamlit_app.py
