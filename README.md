# 🪐 ExoHabitAI – Exoplanet Habitability Predictor

ExoHabitAI is a Streamlit-based AI application that predicts and analyzes
the potential habitability of exoplanets using machine learning.

## 🚀 Live Demo

[ https://exohabitai-ai.streamlit.app/]

## ✨ Features

- Predicts potential exoplanet habitability
- Uses machine learning for classification
- Analyzes important planetary and stellar parameters
- Provides an interactive Streamlit interface
- Displays prediction results clearly

## 🛠️ Technologies Used

- Python
- Streamlit
- Pandas
- Scikit-learn
- Machine Learning

## 📊 Input Parameters

The model analyzes parameters such as:

- Planet radius
- Planet mass
- Planet equilibrium temperature
- Host star temperature
- Orbital distance

## 🧠 How It Works

User Input
     ↓
Data Preprocessing
     ↓
Machine Learning Model
     ↓
Habitability Prediction
     ↓
Result Displayed in Streamlit

## ▶️ How to Run Locally

1. Clone the repository
2. Navigate to the project directory
3. Install the required dependencies
4. Run the Streamlit application
